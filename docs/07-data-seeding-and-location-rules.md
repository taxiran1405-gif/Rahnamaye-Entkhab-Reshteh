# قواعد ورود داده دانشگاه‌ها

نسخه seed همه 31 مرکز استان را پوشش می‌دهد و چند مرکز دانشگاهی عمده غیرمرکز استان را جداگانه ثبت کرده است.

تفکیک حیاتی:
- province_capital
- university_seat_city
- campus_city
- regional_major_center

نمونه‌های کنترل‌شده:
- دانشگاه مازندران در بابلسر است و نباید صرفاً به دلیل مرکز استان بودن ساری، شهر دانشگاه ساری ثبت شود.
- دانشگاه صنعتی اصفهان و مؤسسات مشابه نزدیک کلان‌شهر باید city دقیق و فاصله را مستقل نگه دارند.
- دانشگاه‌های چندپردیسی، institution و campus مستقل داشته باشند.

seed تا زمان تطبیق با سایت رسمی دانشگاه یا سند رسمی مناسب، مبنای انتشار نهایی نیست.
