# Sanjesh Notice Ledger

این پوشه index قابل‌ممیزی اطلاعیه‌های مرتبط با انتخاب رشته است.
هر ورودی:
- سال پذیرش
- نوع اطلاعیه
- عنوان
- مسیر رسمی
- مسیر دسترسی/آرشیو در صورت نیاز
- اثر عملی روی محصول

را مشخص می‌کند.

وضعیت official_mirror یعنی محتوای منتشرشده از سازمان سنجش از طریق یک مسیر آرشیوی/آینه‌ای برای بازیابی ثبت شده و باید پیش از انتشار قطعی، با نسخه رسمی تطبیق داده شود.
