# کتابخانه خام برای ورود بدون اتلاف

این پوشه محل داده خامِ استخراج‌شده از فایل دانش پروژه است. هیچ ردیفی در مرحله خام حذف یا ادغام نمی‌شود.

فرمت مرجع هر ردیف در `schemas/library-raw-row.schema.json` تعریف شده است. هر رکورد باید `raw_sheet` و `raw_row` و اطلاعات lineage را نگه دارد.

فایل `manifest.template.json` فقط قرارداد ورود است؛ تا وقتی استخراج واقعی فایل انجام نشده، نباید با داده ساختگی پر شود.

ترتیب مورد انتظار:
1. استخراج workbook به JSONL/CSV/TSV
2. ثبت تمام ردیف‌ها با lineage
3. اعتبارسنجی
4. normalization به مدل canonical
5. conflict audit
6. backtest
7. انتشار فقط پس از gateهای پروژه
