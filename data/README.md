# داده

این پوشه برای داده‌های canonical و seed است.

## اصول
- داده خام منبع اصلی باید immutable/append-only بایگانی شود.
- داده normalized باید lineage به raw evidence داشته باشد.
- داده‌های قبولی حتماً سال، سهمیه/منطقه، رشته، دانشگاه و نوع دوره را در کلید تحلیل داشته باشند.
- «شبانه/نوبت دوم» با «پردیس» ادغام نشود.
- رتبه کلی و رتبه موضوعی دانشگاه جدا بمانند.
- داده‌های تقریبی/مشاوره‌ای فقط با confidence مشخص وارد شوند.
- داده بدون منبع عددی وارد موتور نهایی نمی‌شود.
