# راهنمای انتخاب رشته ۱۴۰۶

سامانه داده‌محور و چندایجنتی برای «مشاوره انتخاب رشته» با تمرکز اولیه بر گروه‌های ریاضی و زبان و قابلیت توسعه به سایر گروه‌ها.

## هدف نسخه 0.1
- دریافت رتبه، سهمیه/منطقه، سال و ترجیحات داوطلب.
- اتصال فقط به داده‌های دارای منبع و سطح اعتبار مشخص.
- تحلیل مستقل تخصصی توسط ایجنت‌ها.
- تولید پیشنهاد اصلی و رشته‌های موازی/هم‌ارزش در گروه‌های قابل مشاهده و قابل مقایسه.
- اجرای حلقه صحت‌سنجی پیش و پس از تولید هر پیشنهاد.
- ثبت کامل منشأ هر تصمیم، دلیل، عدم‌قطعیت و داده‌های متعارض.
- نگهداری تاریخچه داده برای تحلیل پنج‌ساله و ارزیابی عملکرد واقعی سامانه.

## اصل کلیدی
LLM مسئول «تفسیر، توضیح، استخراج و هماهنگی» است؛ موتور احتمال قبولی و قواعد سخت باید تا حد ممکن deterministic و قابل آزمون باشند.
